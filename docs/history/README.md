# Historische Dokumente

Diese Dokumente bleiben erhalten, weil sie Entscheidungswege, Messungen und offene Fragen dokumentieren. Sie liegen **jetzt alle hier** (P3-6, 27.09.2026), damit ein Agent sie nicht versehentlich als aktuellen Stand zitiert:

- `HANDOFF.md`: chronologische Übergaben und frühere Arbeitsstände
- `verbesserungsplan.md`: strategischer Volltext und ursprüngliche Roadmap
- `analyse-2026-09-23.md`: datierte Gesamtanalyse
- `umbauplan.md`: **abgelöster** Planungsstand vom 24.09.2026 (Nachfolger: `docs/fahrplan.md`)
- `RESEARCH.md`: Gründungsrecherche vom 14.09.2026

Ebenfalls historisch, aber weiterhin am ursprünglichen Ort: `.scratch/` (Tickets, Specs, Research, Messläufe und Nachweise).

Historische Aussagen sind nicht automatisch aktuell. Für das aktuelle Verhalten gelten Code und Tests, für Architekturentscheidungen `docs/adr/`, für die offene Arbeit `docs/fahrplan.md`, für den Stand `docs/current/stand.md` und für Messungen `docs/current/qualitaet.md`.

Ein Ticket oder eine alte Notiz wird erst dann wieder maßgeblich, wenn ein ausführbarer Test oder ein angenommener ADR sie bestätigt.

**Zitate innerhalb dieser Dateien** (`HANDOFF.md` §2.26, `umbauplan.md` Phasen 0–9 usw.) sind bewusst nicht umgeschrieben: sie beschreiben den Stand, aus dem heraus geschrieben wurde, und eine nachträglich korrigierte Fundstelle wäre keine Fundstelle mehr. Wer ihnen folgt, nimmt den neuen Pfad.
