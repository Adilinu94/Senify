# Historische Dokumente

Diese Dokumente bleiben erhalten, weil sie Entscheidungswege, Messungen und offene Fragen dokumentieren:

- `HANDOFF.md`: chronologische Übergaben und frühere Arbeitsstände
- `docs/verbesserungsplan.md`: strategischer Volltext und ursprüngliche Roadmap
- `docs/analyse-2026-09-23.md`: datierte Gesamtanalyse
- `docs/umbauplan.md`: **abgelöster** Planungsstand vom 24.09.2026 (Nachfolger: `docs/fahrplan.md`)
- `RESEARCH.md`: Gründungsrecherche vom 14.09.2026
- `.scratch/`: Tickets, Specs, Research, Messläufe und Nachweise

Historische Aussagen sind nicht automatisch aktuell. Für das aktuelle Verhalten gelten Code und Tests, für Architekturentscheidungen `docs/adr/`, für die offene Arbeit `docs/fahrplan.md`, für den Stand `docs/current/stand.md` und für Messungen `docs/current/qualitaet.md`.

Ein Ticket oder eine alte Notiz wird erst dann wieder maßgeblich, wenn ein ausführbarer Test oder ein angenommener ADR sie bestätigt.

**Noch nicht verschoben:** Die vier Dateien `HANDOFF.md`, `docs/verbesserungsplan.md`, `docs/analyse-2026-09-23.md` und `RESEARCH.md` liegen noch an ihren ursprünglichen Orten, obwohl `AGENTS.md` und dieser Index sie als historisch führen. Das Verschieben ist Teil von `docs/fahrplan.md` P3-6 und bleibt offen, damit ein Agent sie nicht versehentlich als aktuellen Stand zitiert.
